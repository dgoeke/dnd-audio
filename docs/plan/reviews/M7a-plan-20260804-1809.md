# M7a implementation-plan review — 2026-08-04 18:09

**Reviewer:** independent Codex CLI, read-only plan review
**Disposition:** ten findings; nine accepted in full, one accepted in part. Plan amended
before any code was written.

This is the second review of M7a. The [first](M7a-plan-20260804-1707.md) critiqued the
charter's *design* and rewrote it. This one critiques the *implementation plan* written
into the charter's Working plan section, and its verdict was "not yet a plan that can
prove its own completion gate". The design was not challenged; almost every finding is
that a proposed proof is weaker than the criterion it claims to prove — which is the
failure mode this repository's closeouts describe more often than any other.

## Findings and disposition

1. **P0 — the milestone still violated `AGENTS.md`.** The plan amended the product spec
   and INV-06 but not the working agreement, which says "No audio ever leaves this
   machine" and, under **Hard rules**, "Never send audio off the machine". It also caught
   that the spec carries *two* unconditional prohibitions, not one: the firm-scope line and
   a second in the target-host section saying session audio "must never be sent to a URL or
   API". **Accepted.** Four locations are amended together before code, and `AGENTS.md` is
   named in the first completion criterion. The exception is worded narrowly: only an
   explicit `archive` command may send immutable source bytes to the configured
   owner-controlled private archive, and every processing and model path stays local.

2. **P0 — the memory proof could pass an unbounded implementation.** One ordered event log
   across sequential phases is satisfied by an early compressor write even if a later
   remote verifier calls `body.read()` and buffers a whole object. **Accepted.** Events are
   phase-typed, and each boundary is asserted independently: source reads interleave with
   compression writes, staged reads with upload calls, remote reads with decompressor
   consumption, and restore decoding with destination writes, with no size-less `read()`
   anywhere. Disk preflight is tested directly at and just below its computed bound —
   injecting ENOSPC proves cleanup, not that the preflight arithmetic is right.

3. **P0 — the cache-identity freeze did not prove INV-08.** Comparing `config_hash`, the
   five stage projections and final artifact bytes omits the actual cache keys, and ASR's
   identity is not a `stage_config_hash` at all. Identical output bytes after a cache miss
   prove nothing about the key. **Accepted.** The freeze now covers the complete identity
   document and sidecar path of every cache a run touches — inspection, derivative,
   detection, attribution, mix and ASR — measured once warm and once after clearing, so
   output equality cannot hide an identity change.

4. **P0 — the network-boundary proof did not prove INV-06.** "`boto3` is not imported" is
   not "no client was constructed and no socket opened", and the proposed test covered four
   commands while omitting `inspect`, `ingest`, `activity`, `render` and `doctor`. INV-05
   already records that a subprocess escapes the autouse socket fixture. **Accepted.** Every
   non-archive command is invoked as a subprocess carrying a socket-and-client trap on its
   `PYTHONPATH`, the same shadowing technique `tests/test_runtime.py` uses for Torch.
   `models fetch` keeps its pre-existing exception, and the test proves M7a does not widen
   it.

5. **P1 — the pagination assumption was wrong, and the reviewer understated it.**
   DigitalOcean's compatibility page says `ListObjectsV2` is supported while its limits page
   carries a **Known Issues** entry saying verbatim that "The Spaces API does not currently
   support `list-objects-v2` pagination". **Accepted, and resolved more strongly than
   proposed.** Archive v1 uses legacy `ListObjects` marker pagination outright rather than
   putting V2 behind a fallback: a code path that only runs when a provider bug is present
   is a code path nobody exercises. **OQ-028** records the contradiction, and the host smoke
   settles it by writing several generated objects and following every page at `MaxKeys=1`.

6. **P1 — an interrupted restore stranded its own retry.** Publishing each verified file
   atomically while refusing existing targets means an ENOSPC at file 20 leaves 1–19 behind,
   and the retry must then refuse them. **Accepted.** Restore stages the whole tree beside
   the destination, verifies it complete, and renames the directory into place, so a failed
   restore leaves the destination untouched. Space is preflighted as the sum of original
   sizes plus overhead rather than one file at a time.

7. **P1 — refusing unusual `session_id` values broke the charter rather than hardening it.**
   The plan proposed rejecting session ids outside a new pattern, which makes an already
   valid, already inspected session such as `Session 01` unarchivable; narrowing
   `SessionConfig` instead would move every processing identity and contradict the
   isolation this milestone is built on. **Accepted, and the plan's own amendment was
   withdrawn.** The session id is canonically and reversibly encoded exactly like a path
   component. Nothing in `SessionConfig` changes.

8. **P1 — the delete-authority test searched for the wrong spelling.** Scanning for
   `DeleteObject` passes with `client.delete_object(...)` present, and omitting delete from
   the protocol does not stop the concrete adapter calling its own client. **Accepted.** The
   adapter is exercised through a recording client under an explicit operation allowlist;
   `delete_object` and `delete_objects` are rejected by name and `abort_multipart_upload` is
   the only destructive operation permitted.

9. **P1 — the proof table missed most of the operator contract, and the concurrency promise
   exceeded the design.** **Accepted in part.** The coverage half is accepted in full: every
   command, both scopes, unknown tracks, unassigned files, pagination, interrupted upload
   and concurrent upload each get a named test, including two real processes contending for
   the lock. On concurrency the reviewer offered two resolutions; the first is taken and the
   second **rejected**. DigitalOcean's `PutObject` exposes no conditional create, so no
   compare-and-swap exists — the charter is therefore narrowed to promise single-host
   mutual exclusion via the local lock, stated as the precondition it is. Selecting a
   different storage provider is rejected: the bucket exists, and choosing a delivery
   surface is explicitly M7b's.

10. **P1 — path encoding was undefined over bytes versus text.** Linux permits non-UTF-8
    filenames while `canonical_json` emits UTF-8 text, so a surrogate-escaped name would
    fail serialization outright. **Accepted.** Archive v1 freezes its encoding over
    `os.fsencode()` bytes, and the manifest's authoritative `path` field is the
    pure-ASCII percent-encoded byte form — always serializable — with a human-readable
    `path_text` present only when the name is valid UTF-8. Restore reconstructs from the
    byte form. Tests cover `%`, `/`, newline, non-ASCII normalization contrasts, invalid
    UTF-8 bytes, and the key's UTF-8 **byte** length.

## Lower-severity findings, all accepted

- **Botocore has its own retry machinery**, so an injectable retry loop on top of it bounds
  nothing. The client is constructed with SDK retries disabled, making the project's loop
  the only one.
- **The "one manifest object" proof should compare the exact remote key set** against
  `{manifest} ∪ manifest.object_keys`; counting keys outside `objects/` would miss a report
  accidentally written beneath it.
- **Scanning committed prose and literal API names is brittle ceremony.** The test that
  read INV-06's committed text was dropped; `scripts/check_plan.py` already enforces
  reference integrity, and behavioural boundary tests carry the real weight.
- **The retrieval cost message overstated the bill.** The documented $0.01/GiB fee is waived
  up to average daily Cold Storage usage, and the message says so.

The reviewer also judged seven ADRs to be documentary over-building against several absent
behavioural proofs. **Partially accepted:** the two weakest are merged into their neighbours
— the dependency decision belongs to the archive-v1 recipe, and the provider permission
boundary belongs to the network exception — leaving five, each recording a decision rather
than restating the charter.

## Result

Nothing about the archive design changed. What changed is that eight of the ten proofs the
plan named have been replaced by ones that can actually fail: real cache keys instead of
output bytes, subprocess socket traps instead of import checks, an operation allowlist
instead of a name grep, phase-typed interleaving instead of one ordering assertion, and a
transactional restore instead of a per-file one. The raw reviewer transcript remains
ignored because it quotes local operator notes.
