# M9 plan review — Codex, 2026-08-04

Independent critique of the working plan in
`../milestones/M9-transcript-assembly-quality.md`, run before implementation with
`./scripts/codex-review.sh plan M9`. Distilled from the raw transcript, which is gitignored
because a reviewer may quote every file it reads, including `LOCAL.md`.

**Verdict:** no P0 invariant violation, but the plan was not ready to implement unchanged.
The reviewer found five P1 contract failures and two P2 proof/documentation gaps. **All seven
are accepted.** The charter was amended before source changes.

## Accepted P1 findings

### 1. A per-pair fallback would change legacy collapse outcomes

The proposed "old rule first, then containment" ordering was only within each comparison.
Because comparisons are globally score-ordered and skip already-collapsed participants, a new
high-scoring containment edge could remove a segment before its legacy similarity comparison.
That would change both the old survivor and audit decision without changing the old predicate.

**Disposition:** run the complete existing similarity algorithm as the first global pass, then
run `contained_fragment` only over its survivors. Freeze representative legacy verdicts and
their existing decision serialization. New rule identifiers are emitted only for the new path.

### 2. Shared request lineage is batching evidence, not turn-boundary evidence

`transcript.merge_gap_ms` permits a 1.5-second batching gap to avoid model overhead. Treating a
shared request as sufficient to join public records could merge distinct statements by one
speaker.

**Disposition:** shared request lineage remains necessary, but an independently named
exact-sample presentation-gap threshold is also required. Its provisional 350 ms default is
the smallest rounded setting above the measured target split's 320 ms word gap; it is
registered under OQ-018 and cited from configuration and grouping code.

### 3. Coalescing can invalidate granular overlap flags

Two individually short same-speaker records can each fall below the overlap threshold against
a long different-speaker segment, while their coalesced span exceeds it. Copying either
granular flag would contradict the public artifact's overlap definition.

**Disposition:** recompute overlap using exact samples after presentation turns are built. A
specific regression has another speaker spanning the gap, not merely intervening in sort order.

### 4. Aggregate original/effective bounds cannot audit ownership grace

An alignment-fallback record may represent several source candidates separated by gaps. One
aggregate original range and one aggregate effective range cannot show which piece received
grace, where predecessor clipping occurred, or whether a word could be claimed twice.

**Disposition:** records gain candidate/piece-specific interval lineage: candidate and request
identity, activity and effective bounds, and the submitted padded bounds that constrain grace.
Validation requires each effective interval to remain inside submitted audio and each aligned
word start to resolve to exactly one effective interval. Original request ownership is never
overwritten.

### 5. The charter contradicted itself on byte stability and schema migration

It required legacy collapse artifacts to remain byte-for-byte unchanged while also proposing a
new rule field for every decision. It also did not choose between optional additive fields and
an artifact schema-version bump after M4 froze schema version 1.

**Disposition:** the gate now promises identical legacy survivor verdicts and existing decision
representation, not whole-record bytes after an assembly-version change. The new rule name is
limited to new containment decisions. New lineage is optional additive with explicit legacy
fallback unless an ADR records an artifact schema bump; required fields will not be smuggled
into version 1.

## Accepted P2 findings

### 6. Cache and mix proofs were indirect

A warm run after changing grace does not prove that assembly semantics stay out of ASR identity,
and an unchanged selected mix identity is weaker than INV-09's artifact claim.

**Disposition:** add a direct identity-document assertion, plus a nonempty warm integration run
whose hit count equals planned submissions, miss count is zero, and existing ASR raw documents
and sidecars remain byte-identical. Hash the cached mix intermediate itself before and after.

### 7. Every new empirical default needs OQ ownership and code citations

The 20 ms grace belongs to OQ-027; the 300/1000 containment margin and exact-short safety remain
under OQ-018; the new presentation gap is another unproved conversational/model assumption.
The existing 100/1000 similarity margin cannot be reused for containment.

**Disposition:** give containment its own configuration field defaulting to 300/1000; register
the presentation-gap assumption in OQ-018; update OQ-018/OQ-027 and cite them from each setting
and transform/predicate. ADRs describe the deliberate semantics but do not close the empirical
questions.

## Net effect on M9

The implementation order is now ownership partition first, legacy-preserving two-pass collapse
second, and bounded presentation grouping plus public-overlap recomputation third. The records
contract is piece-specific, cache separation is proved both structurally and end to end, and
request batching is explicitly prevented from becoming an accidental conversational model.
