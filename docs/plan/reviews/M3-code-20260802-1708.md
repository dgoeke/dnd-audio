# M3 — independent code review (Codex), 2026-08-02

`scripts/codex-review.sh code M3`, against `main..HEAD` on `milestone/M3-activity`.
Distilled from the raw session, which is gitignored because it quotes every file it read.

Six findings. Two were invariant violations that a reviewer reading only the M3 diff would
have been entitled to miss — both were verified by reproducing them before anything was
changed, and both are fixed on this branch with a regression test proven to fail without the
fix. A second independent reviewer (fresh context, `feature-dev:code-reviewer`) returned no
findings at its confidence bar, and independently raised the sub-threshold observation that
became finding 3.

---

## 1. INV-08 — inspection cache entries committed before raw verification (fixed)

`timeline/runner.py::_inspect` returned a docstring promising the cache came back
**uncommitted**, "published by the caller once INV-01 has been re-verified", and then called
`cache.commit()` three lines below it. Both callers commit again after `verify_unchanged`, so
the second commit looked like the real one and the ordering looked correct.

Reproduced before fixing: a run that correctly failed on a source mutated mid-flight left
**twelve** `work/cache/inspect/*.json` sidecars keyed on the bytes it had read. Restoring the
original file makes every one of them a valid hit forever — the exact failure INV-08 names,
one layer above the derivative cache where M2's verify phase found and fixed it.

The regression test in `test_activity_run.py` asserted only over `DETECTION_DIRNAME`, so it
could never have caught this. It now globs every sidecar under `work/cache`, which has no
such blind spot for whatever M5 caches next.

The defect predates M3 — it is on `main`, and the lying docstring with it. M3 is where it was
found, and M3's own charter is what made it findable, so it is fixed here.

## 2. INV-13 — a failed run left a `timeline.json` its own report disowned (fixed)

`run_activity` writes `work/timeline.json` before attribution, because the attribution cache
key is keyed on its hash. Its exception handler removed only `activity.json`. A detector
failure therefore left a timeline on disk that the same report calls `reconstruct: failed`
and does not list among its deliverable hashes — and M4 and M5 both read that file.
`run_ingest` had the right behaviour already; the composed runner regressed it.

Now removed alongside the graph. The new test starts from a *valid* timeline written by a
good run, so it distinguishes "removed it" from "never got that far".

## 3. The speech-reference estimator disagreed with ADR-0014 (reconciled)

ADR-0014 specified "the robust (median) band-limited level of that track's own
**high-confidence** candidates". The implementation takes the **75th percentile of every**
candidate, with no confidence filter. Raised independently by both reviewers.

The implementation's choice is defensible and its reasoning was already in the code — a
bleed-heavy track's *median* is a bleed level, which would anchor the veto at bleed. But the
two rules differ in a way that matters: p75-of-all sits systematically **higher** than
median-of-high-confidence, and a reference set too high weakens the veto for that wearer's
quieter speech. The opposite error (too low) is the conservative one the spec prefers.

Not tunable against synthetic audio whose bleed is a delayed copy of its source. So: ADR-0014
amended to record what was built and both failure directions, `REFERENCE_PERCENTILE` now
cites **OQ-017**, and OQ-017 extended to name the estimator as something the first real
session settles. No behaviour changed — inventing a threshold from the fixture would have
been worse than recording the uncertainty.

## 4. `ambiguous` and `vetoed_by_track_level` meant less than the ADR claimed (fixed + reconciled)

ADR-0014 said a candidate "satisfying some but not all of the conditions" is marked
`ambiguous`. The implementation marks only the veto case. The narrower meaning is right — a
flag that fires on every merely-overlapping candidate carries no information — so the ADR was
amended rather than the code.

The second half was a real defect. `_outcome` checked the veto **first**, so every pair on a
vetoed candidate was labelled `vetoed_by_track_level`, including pairs whose competitor was
quieter or unrelated and where suppression was never on the table. An operator auditing why a
speaker survived read "the veto saved this" against a competitor that never threatened it.
The veto is now reported last, for comparisons that had already satisfied margin and
correlation. The gate's decision never consumed that label; the audit trail did.

## 5. The INV-09 field allowlist freezes shape, not provenance (deferred)

The allowlist is described as "how INV-09 is actually enforced". It is the strongest available
mechanism and it does what it claims — but `ActivityDecision.detail` and `ActivityNote.message`
are unrestricted strings on the allowlist, so a later stage could place text-derived content
in either without adding a property or changing the activity package's imports, and every
stated enforcement test would stay green.

Accepted as a real limit on the claim, not a defect in the artifact: today's producer is
acoustic-only. Recorded in M3's closeout, and M5 — which owns INV-09 *enforcement* — must not
read those fields when deriving gain envelopes. Rejected as a fix-now: constraining free text
by test would mean pattern-matching prose, which fails for the wrong reasons.

## 6. Pair comparison is quadratic in all session candidates (deferred)

`compare_pairs` enumerates every pair in the session via `itertools.combinations` and only
then rejects non-overlaps. Candidates are already sorted by start sample, so a sweep would be
`O(n log n)` plus the pairs that genuinely overlap.

Deferred with no measured evidence in either direction: the per-pair work rejected is an
integer comparison, and a real session's candidate count is unknown until the full live run. Recorded in the
closeout with the fix named. Nothing in the completion gate covers throughput, and inventing
a synthetic 20 000-candidate benchmark would measure the fixture generator.
