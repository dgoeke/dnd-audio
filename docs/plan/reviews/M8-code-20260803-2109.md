## Findings

### 1. A generated timeline still claimed BWF references count from real midnight — accepted

`timeline/origin.py::_warn_about_mixed_domains` emitted *"this session mixes BWF sample
references, which count from real midnight, with timecode tags"*. `TimelineNote` is a
serialized model, so that sentence ships into `timeline.json` — which makes it the one place
defect 3's false semantic survived, in the artifact the criterion is written about.

Nothing could have caught it. `test_origin.py::test_mixed_domains_warn_only_where_the_day_
lengths_differ` asserts the note's *code* and never reads its message, and
`test_timeline_artifact.py::test_neither_artifact_says_since_midnight` runs the canonical 30F
fixture, where the note is never emitted at all, and searches for the narrower phrase "since
midnight".

Reworded to say both domains count from the recorder's own origin and that what differs is
their cycle *length*, which is the only thing the warning was ever about.
`test_the_mixed_domain_warning_does_not_claim_either_origin_is_midnight` now asserts the
message text.

### 2. Explicit sync-QA thresholds validated against the frame rate, not the quantum — accepted

`SessionConfig._check_offset_threshold_is_measurable` derived its floor from
`1000 / timecode.frame_rate` alone. At the default 30F that coincides with the 1600-sample BWF
quantum, so it was safe by accident; at `60F` it accepted `offset_warn_ms=20` against evidence
that still moves in 33.375 ms steps. A stated threshold **replaces** the evidence-derived one
outright (`syncqa.run_sync_qa`), so the validator is the only thing standing in the way.

Reproduced end to end before fixing: a `60F` session with a 25 ms cross-receiver offset —
inside the quantum, therefore healthy — raised `timecode_disagreement` twice.

This is defect 5a reinstated at exactly the rate the charter amended its own criterion to
cover, and the two halves each passed alone:
`test_the_floor_comes_from_the_evidence_not_the_configured_frame_rate` tests the *default* at
60F, and `test_an_unmeasurable_threshold_is_refused_rather_than_widened` tests the *refusal* at
30F where the two floors are indistinguishable.

The floor is now the coarser of the two, matching `offset_floor_samples`. Covered by
`test_a_stated_threshold_is_refused_against_the_quantum_not_the_frame_rate` (all three
branches, including `bwf_reference_quantum_samples=1` restoring the frame floor) and
`test_a_healthy_60f_session_inside_the_quantum_raises_nothing`.

### 3. `reference_candidate_count`'s contract contradicted its implementation — accepted

Codex only. The field's docstring said it *"equals `candidate_count` when the fallback supplied
one"*; `bleed.attributed_speech_references` deliberately returns **zero** there, and argues for
zero in its own docstring. The report renderer trusted the docstring and printed *"measured
from all 0 of its candidates, because none won attribution outright"* — a line that contradicts
itself in one breath.

The implementation is right and the documentation was wrong: zero means "no attributed
candidates behind this reference", and `speech_reference_mbfs` is what separates a fallback
reference from an absent one. Docstring corrected to say that; the renderer now quotes
`candidate_count`.

## Found by the verify phase itself, not by either reviewer

- **The `.venv-rocm` suite was failing.** `test_qwen_smoke.py::TestOq018TimestampStability`
  raised a 6160 ms outlier against a 1000 ms bound. Neither reviewer ran the host_smoke suite;
  the charter's first criterion requires it. Diagnosed to a real aligner behaviour, registered
  as **OQ-027** — see the closeout.
- **The charter's stated proof for defect 5a's INV-04 half does not work.** It asks for "a lag
  exactly one sample either side of the threshold, which no float-millisecond comparison
  resolves correctly". Measured: at 16 kHz an integer-millisecond threshold converts to a whole
  number of samples exactly, so the two formulations agree on every integer lag at every
  threshold in both signs. A boundary test justified that way would have been a test that
  cannot fail for its stated reason. Split into the claim it can observe (the comparison is
  strict and symmetric) and an AST check that no `*_ms` value is ever an operand of a
  `Compare` — mutation-verified by reintroducing the float comparison and watching it fail.
- **The calibrated fixture's can-fail proof was prose.** `bleed_dominated_session` was asserted
  to reproduce defect 1 only in a docstring. Measured by reverting the estimator: the old rule
  gives a **16.73 dB** spread across four identically-set transmitters with three references
  sitting on the bleed, the new one **1.20 dB** with all four on speech. Now asserted from the
  artifact alone, which is also diagnostic 8's criterion.
