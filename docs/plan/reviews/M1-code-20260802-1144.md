# M1 code review — Codex + independent reviewer, 2026-08-02

Two independent passes over `git diff 6fefac1..HEAD` on `milestone/M1-inspection`, run
during the verify phase. Distilled from the raw sessions (gitignored: a reviewer
transcript quotes every file it read, `LOCAL.md` among them). Paths are
repository-relative.

Both reviewers reproduced their findings rather than asserting them. Between them they
found nine defects; self-review found three more. **All twelve were accepted and fixed**
— none deferred, none rejected. The verdict before the fixes was that the mechanical gate
passed and the completion gate did not, which was correct.

---

## The two that mattered most

### INV-01 was bypassable with one symlink (Codex, P0)

`_reject_outputs_inside_raw()` compared *lexical* `PurePosixPath`s. With
`output -> raw/tx-a`, `output/ingest-report.json` does not look like it is inside `raw/`,
so the run exited 0 and wrote a report into a track's source directory. The raw snapshot
could not catch it either: the report is written *after* the snapshot is verified.

Fixed by resolving every candidate path and every protected directory before comparing.
That surfaced a second half nobody had considered: when the offending location is the
report's own, writing the failure report there commits the very violation being reported.
So that one case writes nothing — INV-01 outranks INV-13 there, because a report is
regenerable and a source directory written into is not. The CLI prints the structured
error and exits nonzero.

### An invariant check that silently did nothing (independent reviewer, High)

`_raw_roots()` dropped `"."` from the set of protected roots. Reasonable on its face —
every relative path is under `"."`, so the output check would fire on all of them — but
`TrackConfig` permits `input: "tx-a"`, a track directly in the session root. For such a
session the snapshot was **empty**, so `_verify_unchanged()` compared two empty dicts and
INV-01's charter-mandated proof passed no matter what happened to the sources.

The reviewer's note on why it went unnoticed is the useful part: the fixture generator
always writes `input: raw/<track_id>`, so that configuration shape had never been built
and inspected in the suite. Fixed by keeping `"."` for the snapshot (excluding this
pipeline's own `work/` and `output/` by name) and special-casing it only in the output
check, where the false-positive problem actually lives. The regression test modifies a
source mid-run, because a bug in a verification is only visible when the thing it verifies
actually changes.

## The rest, and what each cost

| Finding | Source | What was wrong |
| ------- | ------ | -------------- |
| A stray file could **displace a track's real recording** | reviewer | Duplicate ranking was `(is_edit, path)`. A stray `raw/aaa.wav` sorts before `raw/tx-a/TX01_…`, so it won — marking Alice's original a duplicate of a file attributed to nobody, and costing the track its source. INV-11 violated from the direction nothing else guarded. Ranking is now `(is_unassigned, is_edit, path)`. |
| A duplicates-only track **crashed with no report** | both | `inactive_reason` keyed off whether *any file* was found rather than whether any was *selected*. Those differ exactly when every file was rejected, and the resulting `None` tripped a pydantic validator uncaught. |
| An **unreadable source** crashed with no report | self | `run_inspect` caught only `DndAudioError`. It now catches every exception and maps unknown ones to `internal_error` — INV-13 has no exemption for failures nobody anticipated. |
| A failed rerun left a **stale successful manifest** | Codex | And the regression test that claimed to cover it started from a clean directory, so it could not see the case its own docstring described. Both fixed. |
| **Non-selected candidates were never probed** | Codex | The spec says "for every candidate audio file, run `ffprobe`". Ignored edits, duplicates, and strays had no container facts, no sidecar, no RIFF inventory — and those are exactly the files an operator asks "why was this ignored" about. Now every candidate is captured; missing timing stays fatal for a *selected* source and becomes a recorded warning for one nothing will use. |
| A cache hit could emit a **dangling sidecar reference** | Codex | Deleting `work/ffprobe/` while keeping `work/cache/` is ordinary. The next run hit cache, exited 0, and wrote a manifest naming files that did not exist — so "the raw FFprobe JSON is retained" held on the first run and quietly stopped holding on every one after. A hit now verifies its sidecar and re-probes if it is gone. |
| **Overrides never reached the report** | Codex | The gate says "prominently in manifest *and* report"; only the first half was done, and the test asserting both never opened the report. |
| **Per-source warnings never reached the report** | Codex | Unexpected sample rate, sample-count disagreement, and RIFF truncation stayed nested in the manifest, invisible to anything reading the structured report. |
| Audio **nested inside an unconfigured directory** was never captured | self | Protected by INV-01's recursive snapshot but absent from the manifest. Unconfigured directories are now scanned recursively; configured track directories stay flat, which is the layout the session contract describes. |
| A failed run reported **`config_hash: "000…0"`** | self | A syntactically valid fabrication. Now `null`, which is what a run that never resolved a configuration actually has. |

## What both reviewers checked and found sound

Worth recording, because these are the properties the milestone is actually built on and
two independent passes failing to break them is evidence:

- **No circular fixtures and no can't-fail assertions** — the failure mode the reviewer
  was told to hunt hardest for. The fixture-truth tests use an independent RIFF reader
  rather than the parser under test; the `time_reference` chain round-trips through
  FFprobe's own `bext` parser and is anchored by hand arithmetic and cross-checked by a
  second encoding.
- **The RIFF/RF64 walker's offset, pad-byte, `ds64`, and truncation arithmetic** is
  correct against hand-verified cases.
- **`frame_index()`'s drop-frame math** matches the standard SMPTE formula, and rational
  rates never touch a float.
- **ADR-0006's tagged union** is genuinely never collapsed end to end. Codex explicitly
  said the amended M1/M2 timing boundary is sound and that the problems were
  implementation and proof gaps rather than that boundary.
- **The cache-identity tests** vary one component at a time *and* prove the runner
  consults the cache — a perfect key nothing reads would pass the first half alone.
- **INV-02/03/13 proofs are behavioural**, not structural: injected clock and cache state,
  a relocated session, and real CLI failure paths.

## Rejected

Nothing. Every finding from both reviewers was reproducible and was fixed in this
milestone.
