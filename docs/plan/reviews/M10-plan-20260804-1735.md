# M10 independent plan review — 2026-08-04 17:35

**Reviewer:** independent Codex CLI, read-only plan review
**Disposition:** nine findings accepted; charter corrected before implementation

The reviewer approved the canonical-byte/player direction but would not implement the first
draft. Three invariant-level omissions and an invalid drift inference made the measurement
contract unsafe. All findings below were accepted; no implementation code had been written.

## Findings and disposition

1. **Critical — the analyzer was not an INV-01-safe composed command.** Merely checking raw
   hashes did not cover resolved output symlinks, cleanup ordering, or mid-run mutation.
   **Accepted.** M10 now requires output declaration/carve-out before cleanup, full source
   snapshot and pre-publication verification, and `run_marker_analyze` in the central composed-
   command invariant matrix.

2. **Critical — the separate report lacked INV-13 semantics.** **Accepted.** The charter now
   defines overall/stage status, structured failures and warnings, deliverable hashes, atomic
   failure reporting, partial-success exit behavior, and the difference between an inconclusive
   measurement and a failed command.

3. **Critical — fixed phone position alone cannot isolate recorder drift.** A moving lav changes
   propagation delay even when recorder clocks are perfect. **Accepted.** Every result reports
   differential acoustic arrival; only fixed phone-and-lav geometry permits a clock-drift
   classification. H1, H2, OQ-025, STATE, ROADMAP, and the operator runbook carry the same rule.

4. **High — repeated-marker grouping and start/end pairing were undefined.** Pairing by index or
   strength can shift events after one miss or select a moved-phone diagnostic. **Accepted.**
   The analyzer uses reference-anchored occurrences, one-to-one bounded association, explicit
   unmatched detections, local ambiguity after accepted-event exclusion, and independent event
   roles/geometry IDs. Default windows may pair only when each has exactly one accepted event.

5. **High — marker-v1 selection was circular.** The public v1 builder could not be proven before
   the bench that selects v1. **Accepted.** Private candidate tooling and the physical bench now
   precede the ADR that freezes the integer PCM, anchor, thresholds, and hash; public v1 build
   and analysis follow.

6. **High — marker configuration/cache identity was promised but not designed.** Adding marker
   settings to `SessionConfig` would change its global hash, and trusting an existing timeline
   would permit stale analysis. **Accepted.** M10 uses a separate versioned invocation/event-log
   model with complete analysis identity and read-only current-source/manifest/timeline
   validation. Existing processing configuration and caches remain untouched.

7. **High — bounded search windows did not prove INV-07.** A multi-hour requested interval could
   still become one large FFT allocation. **Accepted.** Fixed-size overlap-save processing,
   template carry, online normalization/suppression, and a composed progress-before-last-read
   memory test are required.

8. **Medium — exact coordinate, warning, and perturbation semantics were incomplete.**
   **Accepted.** The charter defines a frozen marker anchor, half-open intervals, lag sign,
   source path/sample coordinates, equal-score tie-breaks, M8's timecode-quantization warning
   floor, an actual drift warning under fixed geometry, and sample-rate/time-scale tests.

9. **Medium — manifest self-hash and multi-file publication were ambiguous.** **Accepted.** The
   manifest explicitly excludes itself and is atomically published last after the WAV and HTML
   have been written and validated.

## Scope restraint retained

M10 does not add Wake Lock, a public candidate-management CLI, source localization, a hosted
application, automatic whole-session scanning, or browser automation presented as acoustic
proof. The browser test owns only offline byte transport/playback state; the phone/DJI bench
owns physical fidelity.

## Result

The revised charter is ready to guide implementation. The HTML remains valuable precisely
because it embeds the CLI WAV bytes rather than synthesizing a second approximation; the plan
now also states where that exact digital equivalence ends and physical acoustic evidence begins.
The raw reviewer transcript remains ignored because it can quote private local notes.
