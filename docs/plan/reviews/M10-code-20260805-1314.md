## Findings and dispositions

1. **P0 — current raw bytes were not compared with the ingest manifest. Accepted.** The
   entry/exit snapshot proved only that bytes stayed stable *during* analysis. The analyzer now
   compares every timeline-selected source's current size/hash with `manifest.json` and fails
   `manifest_stale_source` if a source changed after ingest.
2. **P0 — the occurrence ceiling was checked after unbounded peak accumulation. Accepted.**
   Per-chirp candidates are now retained in bounded maps; a separate 256-candidate ceiling and
   the 32-occurrence ceiling are checked after every block, and occurrence count is also bounded
   across disjoint intervals. Dense complete-marker and isolated-chirp tests prove failure before
   the last read.
3. **P1 — overlapping or repeated logged events could silently select a role/pair. Accepted.**
   Role proposals are matched globally; one occurrence claimed by multiple events stays
   unassigned. Differential comparison requires exactly one start and one end group.
4. **P1 — an event log for another session was accepted. Accepted.** A session-ID mismatch is
   now a structured fatal error before role or geometry evidence is used.
5. **P1 — the reported consecutive-gap tolerance was not enforced. Accepted.** The assembler
   now rejects when any actual inter-chirp gap error exceeds 1440 samples, in addition to its
   anchor-relative search bound.
6. **P1 — incomplete multi-track evidence could set `inconclusive: false`. Accepted.** An
   analysis is conclusive only when it has a group and every group member is a clean detection.
7. **P1 — six generated HTML/manifest outputs were tracked. Accepted.** They were removed,
   `/bench-markers/` is ignored, and a repository-content regression rejects tracked marker
   WAV/HTML outputs.
8. **P1 — several claimed proofs were incomplete. Accepted.** Exact-anchor coverage now requires
   every independently expected track; analyzer-level missing, weak, clipped, and ambiguous
   outcomes are exercised; skipped and partial report-model states are tested; M8's within-
   quantum result is asserted; and analysis identity now includes the consumed manifest schema
   version.
9. **P2 — ADR-0042 said 25 ms fades while v1 uses 10 ms. Accepted.** The human-readable recipe
   now agrees with the frozen 480-sample fade and WAV hash.
10. **P2 — automatic reference selection was justified by an uncited proximity assumption.
    Accepted.** The implementation comment now states the actual deterministic policy: maximize
    usable reference groups, then break ties lexically. It makes no hardware-location inference.
11. **P2 — repository state still described the pre-bench milestone. Accepted.** This is
    resolved by M10 closeout: `STATE.md`, `ROADMAP.md`, and the charter record the selected v1
    and make H1 the next milestone.

Detector semantics moved to v3, analysis semantics to v2, and analysis schema to v3. The
