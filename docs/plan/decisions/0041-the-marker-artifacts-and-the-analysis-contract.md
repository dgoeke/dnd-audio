# ADR-0041 — The marker artifacts, the candidate registry, and the analysis contract

**Status:** accepted
**Date:** 2026-08-05
**Milestone:** M10

## Context

M10 adds two commands, three artifacts and a detector. The charter describes what they must
do; it deliberately left the exact contracts open, and the second plan review
(`../reviews/M10-plan-20260805-0606.md`) found five of them still undefined at the point where
implementation was about to start — the score's representation, the event log's units, role
assignment across overlapping intervals, the analysis identity's coverage, and the bound on
retained occurrences. Each is the kind of thing that is free to decide now and expensive to
change once a schema is checked in and a golden hash is frozen.

This ADR settles them before production code. ADR-0040 settles what the measurements *mean*;
this one settles how they are represented.

## Decision

### 1. One generator, one detector, and a candidate registry rather than a frozen v1

The CLI WAV and the phone page must not be two synthesizers — the charter says so, and the
same argument applies one level up to a private bench toolchain beside a public builder. There
is **one** synthesis function, **one** page builder and **one** detector, and the bench drives
them through the shipped commands.

`MARKER_SPECS` is a frozen registry mapping a name to a complete `MarkerSpec`. Until the bench
selects a winner it contains candidates only — **there is no `v1` key** — so
`marker build OUTPUT_DIRECTORY` with no `--marker` exits nonzero naming the bench. The
charter's "nothing is called public `v1` before the physical bench selects it" is therefore
enforced by an absent key rather than by convention.

`--marker` is **hidden**, documented in the bench protocol rather than in `--help`, so the
charter's non-goal excluding "a public candidate-management CLI" is honoured on the surface
that matters. The first plan review's finding 5 called v1 selection circular and prescribed
private tooling; the circularity was in writing a builder *against v1*, and parameterizing by
spec removes it, where duplicating the toolchain only routes around it — at the cost of the
bench never exercising the CLI wiring, which is exactly where M7a's P0 lived.

### 2. Synthesis is exact integer arithmetic, and no `libm` result reaches the bytes

A frozen SHA-256 over floating-point output would be a promise about one platform's `libm`.
So the phase of a linear chirp is computed in closed form, in integers. For a chirp from `f0`
to `f1` Hz over `N` samples at rate `R`, the phase in turns at sample `n` is

```
phase(n) = [ n·f0·(N−1) + (f1−f0)·n(n−1)/2 ] / ( R·(N−1) )
```

— every term integral for integer `f0`/`f1`, `n(n−1)/2` always integral, and a **closed form
rather than an accumulation**, so nothing compounds. The table index and its interpolation
remainder come from one integer division by `R·(N−1)`.

Sine comes from a checked-in quarter-wave integer table, `marker/data/sine_table.json`,
regenerated by `scripts/design_sine_table.py`. This is deliberately M2's pattern for the
decimation FIR (`data/fir_48k_16k.json` + `scripts/design_fir.py`), including its rule: **the
tests are the contract, not the array.** The table is verified by its endpoints, quarter-wave
monotonicity, the symmetry identities the evaluator relies on, and a stated maximum error
against `math.sin` — never by comparing it to a stored copy of itself.

The amplitude envelope is a raised cosine from the same table over an integer number of
samples. There is **one** rounding, half away from zero, at the single point where fixed point
becomes an integer sample.

### 3. Scores are integer permille, and every comparison happens there

The detector produces floating correlation values; the analysis artifact contains no floats,
for the reason `timeline.json` contains none. Both cannot be true of a serialized float score,
and comparing raw floats against thresholds is **the defect M8 removed from `sync_qa`**.

So a normalized score is quantized once to integer **permille** — the unit already in use for
`similarity_permille` and for the correlation figures in OQ-017 — and every threshold, every
runner-up separation, and every equal-score tie-break is compared in that domain. Tests sit
one unit either side of each boundary.

Ties are broken by lower session sample, then by lexical track identity, then by lexical
source path. Never by list order, and never by peak strength where a role is at stake.

### 4. The event log is a separate versioned input, in integer milliseconds

Marker options are **not** `SessionConfig` fields, for the reason `archive/config.py` records:
a new section moves `config_hash`, every stage projection, and therefore gigabytes of cached
inference (ADR-0016). The event log is its own schema-versioned document, loaded from a path.

Its intervals are serialized as **integer milliseconds** and converted through
`determinism.to_samples` — the one quantizer (INV-04). Taking approximate seconds and
separately rounding each end would be a second quantization path, which is how that rule dies.
Intervals are half-open and clamped to the session, and each carries a **matching halo of the
marker's own length**, so an occurrence whose anchor sits near an edge is found rather than
half-scanned.

### 5. Occurrence grouping, and role assignment as a second one-to-one problem

Accepted occurrences are formed on the **reference track** first under a versioned
non-maximum-suppression radius. Other tracks are associated one-to-one inside a bounded lag
interval around each reference anchor — never by list index, because one missed detection
would then shift every later pairing.

Assigning *roles* is a separate matching problem, and the charter did not say so. Once
configured intervals are unioned for scanning, a single reference occurrence can fall inside
both a `start` and an `end` interval; canonicalizing the searched set prevents detecting it
twice but does nothing about labelling it arbitrarily. Role assignment is therefore also
one-to-one against logged events, tie-broken by playback order, and **ambiguity is reported as
inconclusive rather than resolved into a role**. Absent an event log, a default window may pair
only when it contains exactly one accepted reference occurrence.

The frozen **anchor** is the first sample of the first chirp, expressed relative to the WAV's
first sample. Every interval is half-open. `relative_lag_samples = track_anchor −
reference_anchor`, positive meaning the track heard it later.

### 6. Retained occurrences are bounded by an explicit ceiling that fails

Streaming the correlation bounds the correlator, not the analyzer: accepted occurrences,
groups and unmatched detections accumulate in memory and are then serialized. Non-maximum
suppression bounds *nearby* candidates and says nothing about the number of *separated* ones,
so a long or adversarial range grows them without limit — an INV-07 breach on the composed
path, which the obvious memory proof (a longer *sparse* search) passes straight through.

So there is a **versioned ceiling on retained occurrences, and reaching it is a failure that
names itself in the report.** It never truncates: this project does not do silent caps, and a
truncated occurrence list is indistinguishable from a session that genuinely had that many.
The memory regression uses **dense** accepted candidates.

### 7. The analysis identity covers every algorithm that can move the result

Naming only the marker and detector versions would let a change to event assignment, grouping,
start/end selection, geometry classification or source-coordinate mapping change the analysis
without moving its claimed identity. The identity document therefore carries a distinct
`marker_analysis_semantics_version` alongside the marker and detector versions, the event-log
schema version and a canonical digest of the event log itself, the schema version of every
consumed artifact, the canonical PCM SHA-256, the config/manifest/timeline identities, the
exact half-open searched intervals, the reference track, the thresholds and tie-breaks in
permille, the event roles and geometry IDs, and the NumPy and SciPy versions.

It follows the `derivative_identity_document` shape — **kept separate from its hash so a test
can assert which components are present**, because a key that changes for the right reason can
still be missing the component that matters later (M2's closeout).

There is **no new cache.** Marker analysis runs twice a session; an identity recorded in the
artifact is what the "invalidates only its own artifacts" claim needs, and a cache would be
machinery with its own INV-08 obligations for no benefit.

### 8. Existing artifacts are validated read-only, never rebuilt

`marker analyze` must not rewrite `timeline.json` or `ingest-report.json`, so it cannot follow
ADR-0015's "rebuild, do not validate". It also must not *run inspection*, which the first
working plan wrongly described as an in-memory operation: on a cold or missing sidecar,
`inspection/runner.py::_inspect_one` writes `work/ffprobe/…`.

The validator is built from the source snapshot the run already takes, the contents of
`work/manifest.json`, the currently resolved configuration, and the loaded timeline's own
provenance — and it compares **every** identity component, each with its own diagnostic code
and its own test: `Timeline.config_hash`, `manifest_sha256`, and each of
`timeline_semantics_version`, `inspection_semantics_version`, `numpy_version`,
`scipy_version`, plus schema version and sample rate. Comparing the manifest digest alone
would accept a timeline built by obsolete logic that is still internally consistent with the
same manifest.

### 9. Publication: manifest removed first, then written last

"Manifest last" is a completeness marker for a *first* build and not for a **rebuild**: a
crash between replacing the WAV and replacing the HTML leaves the previous manifest beside a
mixed set, describing bytes that are no longer there. So `marker build` **unlinks any existing
manifest first**, writes and validates the WAV and the HTML, and publishes the manifest last.
Every interrupted state is then manifest-less and therefore detectable.

The manifest does not hash itself (ADR-0003). `marker-report.json` follows ADR-0039's
precedent: a second report at its own command boundary, rather than a seventh stage in
`ingest-report.json` that five commands would have to skip with a reason.

### 10. The page is isolated by an allowlist and a policy, not a denylist

Enumerating known network APIs misses CSS `url(...)`, `navigator.sendBeacon`, form actions and
media/iframe attributes — and misses whatever is added to browsers next year. So the page
carries a `Content-Security-Policy` meta with `default-src 'none'` plus exactly what it needs,
and the test parses the document and asserts **every** URL-bearing attribute is either absent
or a `blob:`/`data:` the page generated itself.

The playback state machine is a declarative JSON transition table that the page's own
JavaScript reads, so the test parses the same table the page runs on rather than grepping for
a guard. What that cannot prove — that the JavaScript applies the table, that `ended` resets
the UI, that the download yields the canonical WAV — belongs to the physical bench, and the
completion gate says so rather than implying a software proof that does not exist.

## Alternatives considered

**Freeze v1 from theory now and treat the bench as confirmation.** Rejected by the charter's
own words and by the operator on 2026-08-05: the exact frequencies, durations, directions,
gaps and level are not knowable from theory, because the question is what a phone speaker and
a lav capsule do to them.

**A float score with a documented comparison epsilon.** Rejected. An epsilon is a second
rounding rule in a project that has exactly one, and M8 already removed this pattern once.

**Disk-backed occurrence spooling** instead of a ceiling. Rejected on proportion: the default
scan is two 120-second windows, and spooling adds a temp-file lifecycle, its own INV-01
surface and its own failure modes to bound something a ceiling bounds in one integer.

**Reuse `fixtures/wav.py`'s `write_wav` for the marker.** Tempting — it already emits exactly
the `fmt `+`data` container needed. Rejected: that module is fixture support and says so, it
writes with `path.write_bytes` rather than atomically, and the marker's byte layout is the
thing being frozen, so it should be stated where it is hashed. The container is instead
*verified* by `inspection.riff.read_inventory` and `timeline.pcm.open_pcm` — two independent
parsers this project already owns, which is stronger than sharing a table with the writer.

**Put the marker's search windows in `session.yaml`.** Rejected; see (4).

## Consequences

The bench can start as soon as Phase A lands, because everything it needs — the candidates,
the page, the detector and the analyzer — is shipped code with its guards in place.

What this makes harder: three semantic version constants now exist where one would have done,
and an implementor changing grouping or role assignment has to remember which one moves. The
identity test that varies each component independently is what keeps that honest, and it is
the reason the identity document is separate from its hash.

What would make us revisit: a bench outcome where no candidate survives at the farthest lav
would move the candidate design space and possibly the detector's shape — which is why the
bench runs before ADR-0042 freezes anything, and why the synthetic regression battery is
parametrized over every candidate rather than written against one.

Every empirical constant here — the gap tolerance, the association lag bound, the clipping and
weak-signal thresholds, the score and ambiguity thresholds, the NMS radius, the "material"
change threshold, and candidate bandwidth survival — cites **OQ-025** or **OQ-029** while
provisional, and ADR-0042 with the measured evidence once frozen.
